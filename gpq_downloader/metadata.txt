about=This plugin connects to cloud-hosted GeoParquet data and downloads just the portion in your current viewport, or in an area you draw or select.

    It comes with pre-configured sources for Overture Maps, Source Cooperative and OpenStreetMap, and you can point it at any online GeoParquet file or partition. You can also save your own sources: add the URLs you use regularly as named groups, and they show up in the download dialog right alongside the built-in ones, with checkbox or drop-down pages, your choice. SQL attribute filters let you download just the features you need.

    Data can be saved as GeoParquet, GeoPackage, FlatGeobuf, DuckDB or GeoJSON. It works best with files that have the bbox struct from GeoParquet 1.1, but any GeoParquet file will work. Your QGIS does not need GeoParquet support, since you can download as GeoPackage, but GeoParquet generally works better (faster, with better nested data handling) - the latest QGIS releases support it out of the box.

    The plugin runs on DuckDB, which the latest QGIS releases ship with. If you are on an older QGIS the plugin will offer to install DuckDB for you, but the smoothest path is a current QGIS. Settings, custom sources and more are documented on the plugin homepage; problems and ideas are welcome on the issue tracker at https://github.com/cholmes/qgis_plugin_gpq_downloader/issues
